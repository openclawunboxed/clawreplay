# pre update checklist

use this before changing openclaw, a model, a skill, memory, a channel, or gateway config.

1. back up your openclaw config and workspace.
2. write down the current openclaw version.
3. run openclaw doctor if your setup supports it.
4. run replay fixtures for important workflows.
5. save the json files from the runs folder.
6. save the markdown files from the reports folder.
7. keep real customer data and secrets out of fixtures.
8. change one major layer at a time when possible.
